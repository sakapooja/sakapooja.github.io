# Pooja Saka — Portfolio

Plain HTML, CSS and JavaScript. No build step.

| File | What to edit |
|---|---|
| `index.html` | All text: hero, about, skills, education, certifications, contact |
| `script.js` | `PROJECTS` list at the top: project text, GitHub and live-demo links |
| `style.css` | Colours and fonts (tokens at the top) |
| `assets/Pooja_Saka_Resume.pdf` | Your resume (replace it, keep the same name) |
| `assets/profile.jpg` | Your photo (add it; portrait ~4:5, under 300 KB) |

Preview: double-click `index.html`, or run `python -m http.server` in this folder and open http://localhost:8000.
Publish: upload the folder contents to a GitHub repo named `YOUR-USERNAME.github.io` and enable Pages, or drag the folder onto https://app.netlify.com/drop.
